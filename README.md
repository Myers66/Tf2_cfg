# Team Fortress 2 — My Custom Config

Мой личный конфиг для Team Fortress 2. Настроен под соревновательную игру (MGE, 6v6) и кастомные режимы вроде Slender Fortress.

---

## 📁 Установка

1. Скачай файл `config.cfg` (или переименуй этот файл в `config.cfg`).
2. Помести его в папку:
3. ...\Steam\steamapps\common\Team Fortress 2\tf\cfg\
3. Для гарантии сделай файл **«Только для чтения»** (Properties → Read-only).
4. Перезапусти игру.

## 🎮 Основные возможности

### 🖱️ Бинды

| Клавиша | Действие |
| :--- | :--- |
| **WASD** | Null-cancelling movement (движение без «мертвой зоны») |
| **TAB** | Таблица очков + net_graph + позиция + FPS |
| **F1** | Перезапуск раунда + оверхил 170 HP (локальный сервер) |
| **F2** | Оверхил 170 HP (локальный сервер) |
| **MOUSE4** | Голосовой чат |
| **MOUSE5** | Скрыть/показать руки с оружием |
| **MOUSE WHEEL DOWN** | Прыжок (для рокет-джампа) |
| **NUMPAD 1-9** | Быстрая смена класса |

## ⚙️ Алиасы (собственные команды)

| Алиас | Действие |
| :--- | :--- |
| `+scoreboard` | Таблица + net_graph + FPS (привязан к TAB) |
| `+spin` | Вращение на месте (меняет `m_yaw`) |
| `ach_off / ach_on` | Включить/отключить уведомления о достижениях |
| `disc` | Быстрый выход с сервера |
| `eazye` | Цепочка фраз в чат (Eazy-E) |
| `loadoutA/B/C/D` | Быстрая смена пресетов A, B, C, D |
| `mvm` | Переключить здоровье над головами |
| `talk` | Голосовые команды по кругу |
| `comp / prec` | Подготовка к записи демо |
| `x` | Самоубийство |

---

## 🛠️ Тренировочные алиасы (только для локального сервера)

| Алиас | Действие |
| :--- | :--- |
| `restart_round` | Перезапуск раунда (`mp_restartgame 1`) |
| `give_health` | Оверхил 170 HP (`hurtme -170`) |
| `rr` | Мгновенный перезапуск раунда + оверхил |

## 💡 Особенности

- **Null-cancelling movement** — движение без остановки при зажатии противоположных клавиш.
- **Жёлтый прицел с чёрной обводкой** — хорошо виден на любых картах.
- **Отображение урона** — жёлтые цифры с суммированием попаданий.
- **Оптимизация FPS** — отключены гибсы, регдоллы, пироландийский режим, тени.
- **Австралийки блестят** — включены эффекты `mat_phong`, `mat_bumpmap`, `mat_specular`.
- **Slender Fortress** — фонарик включён и настроен.

## 🚀 Параметры запуска (рекомендуемые)

Добавь в Steam (Свойства → Параметры запуска): -novid -nojoy -nosteamcontroller -nohltv -particles 1 +exec custom.cfg

---

## 📝 Примечание
Это мой личный конфиг. Некоторые команды (например, `hurtme`, `noclip`, `ent_remove`) требуют `sv_cheats 1` и работают только на локальном сервере.
Если что-то не работает — проверь, что файл называется `config.cfg` и лежит в папке `tf/cfg/`.
